# 合同信息查询系统项目说明

本项目计划开发一个合同信息查询系统，用于集中管理和检索学院相关合同资料。

## 项目背景

当前合同资料主要来自两个渠道：

1. 从招标采购网下载的合同文件。
2. 学院日常业务过程中形成和保存的合同文件。

这些合同资料数量较多、来源分散，后续需要通过系统进行统一整理、索引和查询。

## 系统目标

系统的核心目标是把现有合同资料纳入统一管理，并从合同内容中抽取关键信息，形成可查询、可汇总的数据基础。

## 主要功能设想

1. **信息索引**
   - 将合同文件导入系统。
   - 从合同中抽取合同名称、合同编号、供应商、采购内容、金额、签订时间等关键信息。
   - 建立索引，方便后续按关键词或字段进行查询。

2. **合同查询**
   - 支持根据合同索引信息快速查找相关合同。
   - 支持从查询结果定位到原始合同文件或合同内容。

3. **汇总表生成**
   - 根据合同信息生成所需的汇总信息表。
   - 汇总内容可用于统计、管理、审查或日常办公。

## 当前阶段任务

当前阶段先完成项目目录创建和素材归档工作。已有素材将统一放入本项目目录，作为后续系统设计、数据抽取和功能开发的基础。
